# Agentic AI Portfolio

A growing collection of agentic AI workflow automation projects, built with n8n and modern LLMs. Each project pairs a working workflow with a case study explaining the problem, architecture, and result.

## What I build

I design and ship AI-powered workflows that automate real operational tasks — document generation, structured data extraction, intelligent routing, and multi-agent systems. My focus is the practical, production-ready end of the spectrum: workflows with guardrails, audit trails, and human-in-the-loop checkpoints where they matter.

## Stack

- **n8n** (self-hosted via Docker) — workflow orchestration
- **Google Gemini, Claude, OpenAI** — language models
- **Airtable, Google Drive, Notion** — system integrations
- **Markdown + Loom** — case studies and walkthroughs
